# Russian Diceware 4d6

## Версионирование

Для словаря используются два уровня версий: **издание** (`ed`, edition) и **редакция** (`rev`, revision).

- Новое издание требуется при изменении состава словаря, соответствующих словам комбинаций кубиков, транслитерации, сокращений или числовых кодов. Пароли привязаны к конкретному изданию.
- Редакция может менять вёрстку, оформление, описания и инструкции, но должна сохранять все перечисленные выше параметры словаря. Все редакции одного издания совместимы: для восстановления пароля нужно то же издание в любой редакции.

Нумерация изданий и редакций начинается с 1. В каждом новом издании нумерация редакций начинается заново с 1.

## Структура репозитория

Репозиторий содержит исходные данные словаря и материалы сборки. Выпущенные PDF, CSV и TSV распространяются через GitHub Releases.

```text
/
├── data/
│   ├── external/
│   │   └── fonts/
│   ├── dictionary/
│   ├── attributes/
│   ├── roots/
│   ├── selection/
│   └── wordlist/
└── pipelines/
    ├── attributes/
    ├── roots/
    ├── selection/
    ├── wordlist/
    └── dictionary/
```

## Что где лежит

- `data/` содержит внешние входные данные, промежуточные артефакты и данные отдельных процессов сборки.
- `pipelines/` содержит артефакты, управляющие сборкой: скрипты, промпты, конфиги и служебные пояснения.
- GitHub Releases содержит выпущенные издания и редакции словаря, включая PDF с инструкциями и списки слов в форматах CSV и TSV для программного использования.
