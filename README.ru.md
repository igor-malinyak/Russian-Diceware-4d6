# Russian Diceware 4d6

## Версионирование

Для словаря используются два уровня версий: **издание** (`ed`, edition) и **редакция** (`rev`, revision).

- Новое издание требуется при изменении состава словаря, соответствующих словам комбинаций кубиков, транслитерации, сокращений или числовых кодов. Пароли привязаны к конкретному изданию.
- Редакция может менять вёрстку, оформление, описания и инструкции, но должна сохранять все перечисленные выше параметры словаря. Все редакции одного издания совместимы: для восстановления пароля нужно то же издание в любой редакции.

Нумерация изданий и редакций начинается с 1. В каждом новом издании нумерация редакций начинается заново с 1.

## Структура репозитория

Репозиторий разделён на две верхнеуровневые зоны:

- `dictionary/` содержит конечные пользовательские артефакты Russian Diceware 4d6.
- `source/` содержит исходные данные и материалы сборки, из которых получаются эти конечные артефакты.

```text
/
├── dictionary/
│   ├── editions/
│   └── wordlists/
└── source/
    ├── data/
    │   ├── external/
    │   ├── attributes/
    │   ├── roots/
    │   ├── selection/
    │   └── wordlist/
    └── pipelines/
        ├── attributes/
        ├── roots/
        ├── selection/
        └── wordlist/
```

## Что где лежит

- `dictionary/editions/` содержит редакции словаря, предназначенные для чтения с экрана и/или печати. Инструкции включены в сам словарь.
- `dictionary/wordlists/` содержит списки слов в формате TSV для программного использования.
- `source/data/` содержит внешние входные данные, промежуточные артефакты и данные отдельных процессов сборки.
- `source/pipelines/` содержит артефакты, управляющие сборкой: скрипты, промпты, конфиги и служебные пояснения.
